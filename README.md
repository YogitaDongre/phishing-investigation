# Phishing Email Investigation

A simulated SOC investigation demonstrating phishing alert triage, email analysis, IOC extraction, risk assessment, and incident response.

> **Note:** This project uses a completely fictional phishing scenario and test-domain indicators for cybersecurity training.

---

## 🎯 Project Objective

The objective of this project was to investigate a simulated phishing email from a SOC analyst perspective and document the complete investigation workflow.

### Investigation Workflow

```text
Suspicious Email
       ↓
Email Analysis
       ↓
Identify Suspicious Indicators
       ↓
IOC Extraction
       ↓
Risk Assessment
       ↓
Analyst Verdict
       ↓
Incident Response
       ↓
Lessons Learned
---

## 🔎 Investigation Performed

The simulated email was analyzed for:

- Sender identity
- Reply-To address
- Subject and urgency indicators
- Embedded URL
- Social-engineering techniques
- Potential user interaction
- Potential security impact

---

## 🚨 Key Findings

The investigation identified several suspicious indicators:

- Reply-To address different from the sender
- Urgency-based language
- Account verification request
- Suspicious social-engineering indicators
- Link requesting user action

### Analyst Verdict

**Likely Phishing — Simulated Case**
