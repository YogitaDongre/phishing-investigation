# Indicators of Compromise (IOCs)

## Case

Simulated phishing email investigation.

> All indicators in this project are fictional and created only for cybersecurity training.

---

## Identified Indicators

| IOC Type | Indicator | Purpose |
|---|---|---|
| Sender Email | `it-support@example.test` | Suspicious sender requiring verification |
| Reply-To | `helpdesk@example.test` | Different reply address |
| Domain | `example.test` | Fictional training domain |
| URL | `https://login.example.test/verify` | Account verification link |

---

## IOC Assessment

The identified indicators are associated with the simulated phishing scenario.

No real malicious infrastructure or real-world indicators were used.

---

## SOC Use

In a real SOC environment, identified IOCs could be used to:

- Search security logs
- Search email telemetry
- Identify other affected users
- Support alert investigation
- Block confirmed malicious indicators
- Correlate activity across security tools

---

## Important Note

This project contains only fictional indicators.

The `.test` domain is used specifically for documentation and cybersecurity training.
